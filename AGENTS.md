# Portfolio design preservation

The owner requires the restored portfolio design to be preserved. This applies
to all contributors and automated agents, including Weekly CAPO, Daily Elf,
and Mobster at Work.

The visual baseline is the design published in PR #9 at
`ecdfc63090f9cb42277a53be82efc471be4dbb1f` on November 25, 2026.

## Improve the existing design in place

- Preserve the blue accents, charcoal and light themes, existing typography,
  floating navigation, section hierarchy, contribution chart, and individual
  project artwork.
- Make focused improvements to factual content, links, accessibility,
  responsive behavior, readability, performance, and demonstrated bugs within
  this established visual system.
- Check visual changes against the preserved design at desktop and mobile
  widths, in both themes, and with reduced motion as relevant to the change.
- Carry this constraint into delegated work and automation handoffs.

## Redesign requires an explicit owner request

Do not replace the theme, palette, typography system, page structure, or project
illustrations, or introduce a new visual direction, unless the owner explicitly
asks for that redesign. General requests to improve, polish, modernize, refresh,
maintain, update documentation, or publish do not authorize a redesign.

If an improvement would require changing the visual direction, leave it as a
proposal and ask the owner before implementing it. Do not use a maintenance or
process-documentation task to redesign the portfolio.
